Board Settings → Sharing now shows a public share link once, right after it is created, with a reminder to copy it. When a link was created earlier, the tab says that a link is active and when it expires, and offers **Rotate link** to issue a new one (the previous link stops working). `GET /api/v1/boards/{id}/full/` gains an admin-only `share_link_active` field. Its `share_token` field is **deprecated** and will be removed in 2.0. It is still returned unchanged in 1.2. API clients should read the token from the `POST /api/v1/boards/{id}/share/` response, which returns it when a link is created or rotated (#1935).
