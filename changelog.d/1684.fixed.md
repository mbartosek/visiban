Changing a board's group with `PATCH`/`PUT /api/v1/boards/{id}/` or in the Django admin now updates group pages live, as `POST /api/v1/boards/{id}/move-group/` already did: the old group's channel receives `board.deleted` and the new group's channel receives `board.created`. Previously only the new group received `board.updated`, so the old group's board list kept showing the board until a reload and the new group's list did not show it.
