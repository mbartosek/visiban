Canceling (`DELETE /api/v1/auth/me/pending-email/`) and resending (`POST /api/v1/auth/me/pending-email/resend/`) a pending email change now require an interactive session, like the email change itself. Requests authenticated with a token (a personal access token or the login API token) now get `403 Forbidden` and nothing is changed. This is a deliberate narrowing of accepted credential classes on a low-impact endpoint (#1838).
