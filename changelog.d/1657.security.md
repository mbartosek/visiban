Changing `parent` through `PATCH`/`PUT /api/v1/groups/{id}/` now requires the group owner, an admin of a current parent group, or access to all content, and, when moving under another group, admin of the new parent group (the same rule as creating a subgroup); an unknown group and an unauthorized one return the same `400`. Moves that would create a cycle or nest groups more than 6 levels deep are rejected.
