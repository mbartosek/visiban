Treat an unrecognized stored `export_min_role` as admin-only for board and movement exports, and declare the allowed values as model `choices`. Migration `0086` rewrites a stored value outside the allowed set to `admin` (a blank value to `viewer`); on a board that held such a value, export narrows from everyone with read access to board admins. Boards set through the API or Board Settings are unaffected (#1725).
