Fixed the OpenAPI schema for hand-written endpoints that documented the wrong request or response (#1783). Board and group `star/`, `move-group/`, `saved-filters/` (create), card `archive/` and `unarchive/`, `summary/`, `analytics/`, `export/`, and the group `members/{user_id}/` (role change), `transfer-ownership/` and `board-defaults/` actions now document what they read and return instead of the board, card or group serializer. `PATCH /auth/me/`, `POST /auth/change-password/`, `POST /auth/choose-username/` and `POST /notifications/mark-read/` now document their request bodies. `POST /auth/ws-ticket/` is documented as returning `201` with the ticket, and `POST /auth/registration/resend-email/` as returning `200`. Notably, `DELETE /boards/{id}/star/` is documented as returning `200` with the board, which is what it has always returned. Runtime behavior is unchanged. The API docs also now state that `GET /boards/{id}/export/?format=csv` returns `404`: omit `format` for CSV.
