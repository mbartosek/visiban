- `avatar_url` writes now require an absolute `http`/`https` URL with no embedded credentials, so a profile can no longer point co-members' browsers at arbitrary schemes or userinfo URLs; stored values are unaffected. `/mcp` also gains a per-IP limit on failed token lookups (`MCP_THROTTLE_PREAUTH_RATE`, default `30/min`) applied before the lookup, so unauthenticated guessing can no longer hit the database unthrottled.
