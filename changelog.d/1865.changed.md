Board sharing: the **Sharing** tab in board settings now pre-selects a 30-day expiry for a new public share link; **Never** is still available. The API is unchanged: a share request without `expires_in_days` still creates a link that never expires. A public share link enabled from 1.2 on records the admin who enabled it and is turned off automatically when that admin is deactivated or deleted, or is no longer an admin of the board (demoted, removed from the board or from the group that made them an admin, or no longer given all-content access). An admin who still administers the board another way keeps the link. Links enabled before 1.2 are not affected. (#1865)
