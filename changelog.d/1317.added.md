- Added `GET /api/v1/groups/{id}/descendant-boards/paged/`, which returns the boards under a group and all its subgroups in pages (`offset` and `page_size`, with the standard `{count, offset, page_size, results}` response). It returns the same boards as `GET /api/v1/groups/{id}/descendant-boards/`, which is unchanged and still returns every board in one list. Use the paged endpoint when a top-level group in a large organization holds too many boards for one response (#1317).
