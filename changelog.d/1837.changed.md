Changing a username (`PATCH /api/v1/auth/me/`, `PATCH`/`PUT /api/v1/auth/user/`, `POST /api/v1/auth/choose-username/`) now requires an interactive session. A request authenticated with a personal access token or the login API token that sends a different username receives `403 Forbidden` and nothing is written; other profile edits and sending the current username back unchanged still work with tokens.
