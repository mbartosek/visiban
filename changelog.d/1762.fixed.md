MCP `list_cards` and the `board://{board_id}` snapshot no longer truncate silently at 200 cards: `list_cards` gains optional `limit`/`offset` paging and an opt-in `include_meta` flag that returns `{cards, total, truncated, limit, offset}` (the default result is still a bare array), and the snapshot gains `cards_total` and `cards_truncated` fields (#1762)
