`GET /api/v1/auth/site-config/` now also returns `git_lens_enabled`, `maintenance_mode` and `maintenance_message`, computed by the same code as the `/auth/user/` values, so the two endpoints always agree. **Deprecated:** `maintenance_mode`, `maintenance_message`, `demo_mode` and `demo_next_reset_at` on `/auth/user/` and `/auth/me/`. Read them from `site-config` instead. They are still returned unchanged for all of 1.x, and the OpenAPI schema marks them `deprecated`. `git_lens_enabled` is not deprecated on `/auth/user/`. The bundled web app still reads the `/auth/user/` copies; moving it to `site-config` is tracked in #1913. `site-config` is public, so the maintenance notice is readable without signing in. An anonymous write already got the same notice in its `503` body (#1872).
