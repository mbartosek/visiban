Adding a board member and user search match active users only, and an unknown id and an inactive id return the same `404`; removing a board or group member, and changing a group member's role, resolve through the membership, so an id with no membership returns one `404` whatever the id is (removing a non-member used to return `204`), while an inactive user who has a membership can still be updated or removed; user search matches username and display name only. Board-scoped routes now return `404` instead of `403` to a caller with no access to the board, matching board detail, MCP and media; `403` is kept for a member whose role is too low for the action. The user directory remains open to signed-in users by design, and the security invariants page documents both conventions.
