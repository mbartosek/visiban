Two environment variables introduced in the 1.2 betas were renamed to match the variables around them: `VISIBAN_IMPORT_MAX_SIZE` is now `IMPORT_MAX_SIZE_BYTES` (like `MAX_UPLOAD_SIZE_BYTES`), and `DEMO_USER_THROTTLE_RATE` is now `DEMO_THROTTLE_USER_RATE` (like `MCP_THROTTLE_*_RATE`). The old names still work as deprecated aliases; when both are set, the new name wins. The Helm chart now sets the new names, and its values keys are unchanged. Setting any deprecated environment variable alias now logs a startup warning in the container log. Before, the warning was a Python `DeprecationWarning`, which is hidden by default. The naming convention for new variables is documented in the API compatibility gate guide.
