Four environment variables introduced in the 1.2 pre-releases were renamed to match the naming convention of the variables around them:

- `VISIBAN_IMPORT_MAX_SIZE` is now `IMPORT_MAX_SIZE_BYTES`, like `MAX_UPLOAD_SIZE_BYTES`.
- `DEMO_USER_THROTTLE_RATE` is now `DEMO_THROTTLE_USER_RATE`, like `MCP_THROTTLE_*_RATE`.
- `VISIBAN_MIGRATE_CONNECT_TIMEOUT` is now `MIGRATE_CONNECT_TIMEOUT_SECONDS`.
- `VISIBAN_MIGRATE_LOCK_TIMEOUT` is now `MIGRATE_LOCK_TIMEOUT_SECONDS`.

The old names still work as deprecated aliases. When both are set, the new name wins.

The Helm chart now sets the new names, and its values keys are unchanged. Because of that, use the chart with a backend image from the same release. An older pinned image ignores the new names and uses its defaults.

Setting a deprecated environment variable alias now logs a startup warning in the container log. Before, the warning was a Python `DeprecationWarning`, which is hidden by default. For `OIDC_SECRET` and `ACCOUNT_EMAIL_VERIFICATION`, which were removed in 1.1, the warning now says the value has no effect.

The naming convention for new variables is documented in the API compatibility gate guide.
