The refusal to modify or remove a site admin's board or group membership now applies only when that user already has a membership there; a user with no membership gets the same response as any other user with no membership, and adding a site admin to a board works like adding any other active user (without lowering a role they already hold through a group). For callers who are not site admins, the board member add/update response and the `member.added` / `member.updated` events no longer include `is_site_admin` (the field is optional in the schema); the Members tab re-reads the board to get it.
