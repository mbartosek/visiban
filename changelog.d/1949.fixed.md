A sample board imported as a file (chosen with **Import**, downloaded with `curl`, or posted by an API client) is now dated around the import day, as the in-app gallery already did, instead of keeping its March 2026 dates. Each sample file now carries its `date_anchor`, and the importer shifts a file that has one unless told otherwise; files without it, including every board export, import exactly as before, and an explicit `shift_dates_from` still wins. The Import Board dialog gains a **Dates** section with **Move dates to today** and an **Adjust dates** date field, and the import API gains two optional JSON-only options: `shift_dates` (`false` imports the dates as written) and `shift_dates_to` (date the board around a past day instead of today, UTC).
