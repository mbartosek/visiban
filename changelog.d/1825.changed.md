API: the owner and last-active-admin refusals of `PATCH`/`DELETE /api/v1/groups/{id}/members/{user_id}/` now carry a machine-readable `code` (`group_owner_protected`, `group_last_admin`) next to `detail`, and `GET /api/v1/boards/{id}/analytics/` answers an invalid `days` or `stalled_days` with `{detail, code: "invalid_query_param"}`, the target 400 shape for a bad query parameter (the parameters that still answer a field-keyed 400 are listed in the API errors docs). OpenAPI schema: only the snake_case `set_collapsed` swimlane alias is marked deprecated; the `PATCH` member refusal is documented as `GroupMemberRoleUpdateRefused`; the `POST /api/v1/auth/change-password/` request component is named `AuthChangePasswordRequest` (it was `ChangePasswordRequest` in 1.2 pre-release builds), so it no longer reads as dj-rest-auth's `/auth/password/change/` body; and the dj-rest-auth password-change and password-reset-confirm request components keep their 1.1 names, `PasswordChangeRequest` and `PasswordResetConfirmRequest`, instead of the `VisibanPasswordChangeRequest` and `VisibanPasswordResetConfirmRequest` names in 1.2 pre-release builds. No wire field is removed or renamed (#1825).
