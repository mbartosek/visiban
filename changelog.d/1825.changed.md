API: the owner and last-active-admin refusals of `PATCH`/`DELETE /api/v1/groups/{id}/members/{user_id}/` now carry a machine-readable `code` (`group_owner_protected`, `group_last_admin`) next to `detail`, and `GET /api/v1/boards/{id}/analytics/` answers an invalid `days` or `stalled_days` with `{detail, code: "invalid_query_param"}`, the documented 400 shape for a bad query parameter. The OpenAPI schema now marks only the snake_case `set_collapsed` swimlane alias as deprecated, documents the `PATCH` member refusal as `GroupMemberRoleUpdateRefused`, and renames the `POST /api/v1/auth/change-password/` request component from `ChangePasswordRequest` to `AuthChangePasswordRequest` so it no longer reads as dj-rest-auth's `/auth/password/change/` body. No wire field is removed or renamed (#1825).
