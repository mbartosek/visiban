- Added the `purge_card_history` management command, which lets a superuser erase the movement history that a deleted card leaves behind (its title as recorded at each move, and any movement notes), by card UID, board and/or date range. It is a dry run unless `--yes` is given, refuses to run without a selector, touches only deleted cards' history unless `--include-live-cards` is given, and records each purge in the admin action log as `card_history.purged` with the selector and count, never the purged titles. A new Card History Retention administration page documents how long a deleted card's history is kept and who can see it (#1797).
