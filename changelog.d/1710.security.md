Connecting a sign-in provider from Settings now asks an account that has a password to confirm it first, unless it was confirmed (or the user signed in with a provider) in the last five minutes; signing in to the app with a username and password does not count, so the password is asked for once on the confirmation page even right after such a sign-in. After confirming, the user continues to the provider to finish connecting. Accounts that sign in only through an identity provider are not asked, and their primary email address now receives a notice when a provider is connected. Signing in with a provider is unchanged.
