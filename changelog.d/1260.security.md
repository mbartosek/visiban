Setting a first password on an account that signs in only through an identity provider now requires a recent sign-in with that provider in the same browser session (within allauth's `ACCOUNT_REAUTHENTICATION_TIMEOUT`, 5 minutes by default), on both `POST /api/v1/auth/change-password/` and `POST /api/v1/auth/password/change/`. Otherwise the request answers `403` with `"code": "recent_login_required"`, and Settings asks the user to sign out and sign in again. Accounts that already have a password are unaffected (#1260).
