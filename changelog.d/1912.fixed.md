Revoking a site invite link (`DELETE /admin/invite-links/{id}/`): the OpenAPI schema now declares the real `200` (revoked link body), `400` and `404` responses instead of `204`. Runtime behavior is unchanged and stays different from the other revoke endpoints for all of 1.x; the divergence is documented (#1912).

The group invite-link revoke (`DELETE /groups/{id}/invite-links/{link_id}/`) now also declares its existing `400` response for a consumed link in the OpenAPI schema.
