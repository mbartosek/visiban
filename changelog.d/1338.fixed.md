The Issue Board Lens API is now covered by the API contract checks in CI. Its endpoints are fuzz-tested against the published OpenAPI schema with the lens enabled, and the lens connection response is checked against its TypeScript type. A new CI/test-only setting, `VISIBAN_GIT_LENS_STUB_PROVIDERS`, answers the lens's GitHub/GitLab requests from a fixed in-process fixture during that fuzz run. It is off by default, and the app refuses to start with it set unless `DEBUG=True` and `DEMO_MODE` is off. No runtime behavior changes for existing installs.
