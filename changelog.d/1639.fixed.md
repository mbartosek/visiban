Registering through a site, group or board invite on an invite-only site now sends the signup confirmation email only after the account is saved, so a slow mail server no longer holds up other changes behind the registration's locks; a registration that fails sends no email, and if the email cannot be sent the account is still created and the confirmation can be requested again through `POST /api/v1/auth/registration/resend-email/` instead of the registration failing with a server error (open registration is unchanged).
