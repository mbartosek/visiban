Registering through a site, group or board invite on an invite-only site now sends the signup confirmation email only after the account is saved, so a slow mail server no longer holds the board, group or invite locked; a registration that fails sends no email, and if the email cannot be sent the account is still created and the user can request the confirmation again (once allauth's resend cooldown has passed) instead of the registration failing with a server error (open registration is unchanged).
