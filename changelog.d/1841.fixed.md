`stale_warning_pct` now means what the board settings say: the percentage of the staleness threshold a card has used before the warning tint appears (#1841). The card tint, its tooltip and the analytics heatmap computed it inverted, so the setting only behaved as described at the default 50%. **Boards set to any other value will see their warning point move.** For example, a board at 75% used to warn after 25% of the threshold and now warns after 75%. A value of `0` now turns the warning tint and the heatmap's yellow band off.
