Fixed the OpenAPI schema for swimlanes: schema generation no longer crashes on `board_pk` in `SwimlaneViewSet`, so the swimlane create, update, and partial-update request bodies, the `set-collapsed`/`set_collapsed` request body (`is_collapsed`, required), and the typed read and write responses are now documented. Two swimlane operationIds changed as a result (the list operation `..._retrieve` is now `..._list`, and the detail operation `..._retrieve_2` is now `..._retrieve`), so generated clients will see renamed methods. Runtime behavior is unchanged.
