API: board change-feed rows (`GET /boards/<id>/events/`) gain a nullable nested `actor` (the `BoardUser` shape) alongside the unchanged `actor_id`, resolved with one bulk user fetch per page, so a consumer can label rows by users who have since left the board. The API reference now documents the three actor shapes (nested `BoardUser`, `actor_id`, and `created_by_username` on invite links) and which one new endpoints use (#1663).
