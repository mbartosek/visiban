As a deliberate default change before 1.2 GA, the Helm chart now refuses an empty or placeholder (`visiban`) PostgreSQL password in the bundled-PostgreSQL modes, not only with `postgresql.subchartEnabled=true`; it is skipped only when both `postgresql.auth.existingSecret` and `secret.existingSecret` are set. Existing installs on the default password must set `postgresql.auth.password` before running `helm upgrade`; because PostgreSQL only reads the password when it first initializes its data directory, change the database role's password first. See the upgrade guide (#1864).
