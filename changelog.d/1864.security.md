The Helm chart now refuses the placeholder PostgreSQL password (`visiban`) in every bundled-PostgreSQL mode, not only with `postgresql.subchartEnabled=true`. Existing installs on the default password must set `postgresql.auth.password` (or `postgresql.auth.existingSecret`) before running `helm upgrade`; because PostgreSQL only reads the password when it first initializes its data directory, change the database role's password first. See the upgrade guide (#1864).
