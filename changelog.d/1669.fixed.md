Malformed requests that used to fail with a 500 now get a 400: non-object JSON bodies on board member add, board move-group, column, swimlane, custom field and swimlane custom field reorder, swimlane set-collapsed, group member role change, group board create, notification mark-read, password change, choose-username, personal access token create and invite-only registration (a non-object registration body gets the same response as a missing invite token); ids beyond the database integer range on those reorders, board member add, group ownership transfer and notification mark-read; a non-integer `new_owner_id` on group ownership transfer and non-integer `ids` on notification mark-read; a non-string `swimlane_name` on board create and group board create; and an impossible, non-string or falsy-non-string `expires_at` on personal access token create (an `expires_at` with no UTC offset is now read as UTC). A non-integer `user_id` on board member add used to answer 404 and now answers 400 (#1669).
