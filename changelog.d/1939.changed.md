Public board share links now always need a recorded enabler. A link turned on before upgrading to 1.2.0, including one turned on under a 1.2 pre-release, has none, so it stops opening after the upgrade. The **Sharing** tab shows sharing as off on such a board (`share_link_active` is `false`, and the deprecated `share_token` and `share_token_expires_at` are `null`), and a board admin turns sharing on again under **Board Settings → Sharing**, which creates a new link. See the 1.2 upgrade notes for a command that lists the affected boards.
