Keyboard handling in the movement history view no longer swallows arrow keys typed in filter inputs or open dropdown menus, arrow navigation now moves real focus to the row so Enter opens the detail slide-in, Escape closes an open filter menu first and then only the slide-in (registered on the Escape stack at priority 30, so it no longer also returns to the board), and the table drops its incomplete `role="grid"`. Rows use `aria-current` instead of `aria-selected`, which is invalid on a `<tr>` outside a grid.
