Keyboard handling in the movement history view no longer swallows arrow keys typed in filter inputs or used on filter dropdowns and the detail panel buttons, arrow navigation moves real focus to the row so Enter opens the detail slide-in, closing the slide-in returns focus to its row, and Escape closes an open menu or dropdown first and then only the slide-in (it no longer also returns to the board). The table drops its incomplete `role="grid"`, and rows use `aria-current` instead of `aria-selected`, which is invalid on a `<tr>` outside a grid.
