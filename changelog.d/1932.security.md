Changing or adding an email address on an account without a password now requires a recent sign-in with one of the account's sign-in providers in the same browser session (within allauth's `ACCOUNT_REAUTHENTICATION_TIMEOUT`, 5 minutes by default), the same rule as setting a first password. This applies to `PATCH /api/v1/auth/me/`, `PATCH`/`PUT /api/v1/auth/user/`, and the "Add" and "Make Primary" actions on `/accounts/email/`. Otherwise the API answers `403` with `"code": "recent_login_required"` and Settings asks the user to sign out and sign in again. Accounts that have a password are unaffected (#1932).
