The board change feed response gains `next_cursor` (the integer to pass as `after=` for the next page; the key name matches `/cards/`, but that endpoint takes an opaque string via `cursor`, so the two do not share a request contract). `next` is now deprecated but still returned with the same value through 1.x; the OpenAPI `BoardEventFeedPage` marks it `deprecated`. The pagination shapes decision is recorded in `docs/api/events.md`.
