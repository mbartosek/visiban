Imported comments now work like imported card history: a comment created by a Trello or JSON board import is posted under the user who ran the import, keeps its original time, and keeps the source's author name as text in a new `imported_from_username` field. The card's comment list shows it after the time ("imported, originally Ada Lovelace"), and the comments API, the MCP card resource and JSON export carry it, so a re-imported export keeps the original name. For Trello imports this applies whether or not **Add matched members** is on (that option now affects only board membership and assignees), and the comment body keeps its "(imported from Trello)" line without repeating the author's name.
